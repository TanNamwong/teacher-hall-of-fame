# 🏆 ทำเนียบครูดีเด่น

แอปประเมินและคัดเลือกครูดีเด่นประจำปี ทำงานออฟไลน์ ไม่ต้องมีเซิร์ฟเวอร์/ฐานข้อมูล ใช้ได้ทั้ง iOS และ Android (PWA)

## ฟีเจอร์
- 🌟 ทำเนียบปีปัจจุบัน / 🔎 ค้นหารายปี / 📊 ตารางสรุปย้อนหลัง / 🕘 ประวัติการประเมิน
- ✍️ ให้คะแนนรายหัวข้อ คิดเป็นร้อยละ ผ่าน–ไม่ผ่านทันที
- ⚠️ เตือนตำแหน่งซ้ำ (ตำแหน่งควรหมุนเวียนทุกปี) และแนะนำหมวดที่ยังไม่เคยได้
- 👩‍🏫 จัดการรายชื่อครูพร้อมรูปภาพ
- ⚙️ ตั้งค่าแยกเป็นเมนูย่อย: เกณฑ์ผ่าน/ปีการศึกษา, หัวข้อประเมิน (เปิด-ปิด แก้ไข เรียงลำดับ), หมวดรางวัล, กลุ่มสาระ, สำรองข้อมูล, อัปเดตแอป
- 📄 สรุปเป็น PDF: ทำเนียบ → สรุปรายปี → เลือกปี (หรือทุกปี) → สร้าง PDF แล้วกด แชร์ / บันทึก / เปิดดู (สร้างในเครื่อง ไม่ต้องใช้เน็ต)
- 🖼️ โปสเตอร์ครูดีเด่นประจำปี: ทำเนียบ → โปสเตอร์ เลือกปี โทนสี ใส่ชื่อโรงเรียน แล้วสร้าง ได้รูป JPG ขนาด A4 (เกิน 9 ท่านแบ่งเป็นหลายแผ่น) แชร์ บันทึก หรือรวมเป็น PDF ได้
- 📜 เพิ่มครูดีเด่นย้อนหลัง: ทำเนียบ → เพิ่มย้อนหลัง ใส่ครู ปี หมวด (คะแนนไม่ต้องใส่ก็ได้) เก็บเป็นทำเนียบ นับในตารางสรุป ค้นหา และ PDF
- 💾 สำรอง/นำเข้าข้อมูลเป็นไฟล์ JSON
- 📲 แจ้งติดตั้งลงหน้าจอโฮม (Android กดติดตั้งได้ทันที / iPhone มีขั้นตอนบอก) และมีปุ่มติดตั้งใน ตั้งค่า → ข้อมูล
- 🔄 อัปเดตอัตโนมัติ: ตรวจรุ่นใหม่เองทุก 15 นาทีและทุกครั้งที่เปิดแอป แจ้งเตือนในแอป นับถอยหลังแล้วอัปเดตให้เอง (ถ้ากำลังกรอกข้อมูลอยู่จะรอให้กดเอง) ข้อมูลไม่หาย
- 🔔 แจ้งเตือนเมื่อมีรุ่นใหม่ (ตั้งค่า → อัปเดตและติดตั้งแอป) ตรวจเบื้องหลังได้บน Android Chrome ที่ติดตั้งแอปแล้ว ส่วน iPhone เห็นแถบแจ้งในแอป
- 🎓 ไอคอนมาสคอตคุณครูดีเด่น (รองรับ maskable บน Android)

## วิธีขึ้น GitHub Pages
1. สร้าง repository แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ราก (root)
2. Settings → Pages → Branch: `main` / `(root)` → Save
3. เปิด `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## ติดตั้งลงมือถือ
- iPhone (Safari): ปุ่มแชร์ → เพิ่มลงในหน้าจอโฮม
- Android (Chrome): เมนู ⋮ → ติดตั้งแอป

> ข้อมูลเก็บในเบราว์เซอร์ของแต่ละเครื่อง ควรกด "สำรองข้อมูล" เป็นระยะ ฟอนต์ไทยโหลดจาก Google Fonts ครั้งแรกที่ออนไลน์ หลังจากนั้นใช้ออฟไลน์ได้

## เมื่อแก้ไขแอป
1. แก้ไฟล์ที่ต้องการ แล้วอัปโหลดทับขึ้น GitHub (รอ GitHub Pages ประมาณ 1-2 นาที)
2. จบ ไม่ต้องแก้เลขเวอร์ชัน แอปเทียบไฟล์ `index.html` เอง ผู้ใช้จะเห็นแจ้งเตือนและอัปเดตให้อัตโนมัติ
3. (ไม่บังคับ) ถ้าเปลี่ยนไอคอนหรือรูปและอยากให้เครื่องเก่าล้างแคช ให้เปลี่ยน `VERSION` ใน `sw.js`

> การติดตั้ง/อัปเดตต้องเปิดผ่าน https (GitHub Pages ใช้ได้เลย) เปิดไฟล์ตรง ๆ จากเครื่องจะไม่ทำงาน
